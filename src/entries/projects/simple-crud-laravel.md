My own starter template for interview take-homes and small project assignments. **Laravel Breeze** handles authentication and the dashboard.

It adds a **Repository layer** that talks to the database and sits between models and controllers, which keeps the code cleaner and easier to reason about. You can add an AdminLTE template on top for a richer dashboard.
